# Proyecto Generación del 27 📚✨

Aplicación web desarrollada en el ámbito de la asignatura **Desarrollo Web en Entorno Cliente (DWEC)** de 2º de DAW. El proyecto consiste en una plataforma interactiva dedicada a los autores, obras y contexto histórico de la Generación del 27, implementando un catálogo dinámico, búsquedas avanzadas, validaciones y consumo de servicios externos.

---

## 🚀 Funcionalidades principales

* **Catálogo Interactivo:** Visualización estructurada de los autores y obras literarias de la Generación del 27.
* **Sistema de Búsquedas y Filtros:** Búsqueda en tiempo real por autor, título, género o palabras clave dentro del catálogo.
* **Integración con Servicios Externos:** Consumo de APIs y servicios de datos externos para enriquecer la información literaria.
* **Validaciones Robustas:** Control y validación exhaustiva de formularios y datos introducidos por el usuario.
* **Pruebas y Tests:** Cobertura de pruebas para garantizar el correcto funcionamiento del catálogo, las búsquedas y las validaciones.

---

## 🛠️ Tecnologías utilizadas

* **HTML5 / CSS3:** Estructura semántica y diseño visual responsive.
* **JavaScript (ES6+):** Lógica del cliente, manipulación del DOM, programación asíncrona (Fetch API / async-await) y gestión de eventos.
* **JSON Server / db.json:** Base de datos local simulada para la gestión del catálogo de autores y obras.
* **Herramientas de testing:** Pruebas unitarias y de validación de componentes.
