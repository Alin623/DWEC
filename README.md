# DWEC – Desarrollo Web en el Cliente

Repositorio con los ejercicios de la asignatura Desarrollo Web en Entorno Cliente (DWEC), 2º DAW.

## Contenido

| UD  | Práctica | Tema                                                              |
|-----|----------|--------------------------------------------------------------------|
| [UD2](./UD2) | [P1a](./UD2/P1a) | Instalación y configuración de herramientas de desarrollo web (VSCode, extensiones, Live Server, Git, GitHub, CodeSandbox) |
| [UD02](./UD02) | [P2a](./UD02/P2a) | Ejercicios básicos de JavaScript (bucles, condicionales, etc) |
| [UD03](./UD03) | [Granja](./UD3) | Arrays, Math y objetos: granja con funciones constructoras, toString(), funciones lambda y JSON |
| [UD04](./UD04) | [Marvel](./UD04/Marvel) | Manipulación del DOM: carga de un JSON con `fetch` y generación dinámica de tarjetas Bootstrap con héroes de Marvel (`cloneNode`, `createElement`, `classList`, `appendChild`) |
| [UD05](./UD05) | [Mascotas](./UD05) | Gestión de fichas de mascotas con validación y operaciones CRUD en memoria |
